# Hello World React App

## Description
This is a simple React application that displays
"Hello, World!" on the screen.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   npm install

5. Start the application:

   npm run dev

6. Open the URL shown in the terminal.

## Output
Hello, World!
